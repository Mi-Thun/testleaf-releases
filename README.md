# Testleaf desktop app

Downloads for the Testleaf desktop app, from the **[latest release](../../releases/latest)**:

| System | File | Install |
|---|---|---|
| Windows 10 / 11 (64-bit) | [Testleaf-Setup.exe](../../releases/latest/download/Testleaf-Setup.exe) | open it, then Next → Install → Finish |
| macOS 12+ (Apple silicon) | [Testleaf-mac.zip](../../releases/latest/download/Testleaf-mac.zip) | unzip, drag Testleaf into Applications |
| Ubuntu 22.04+, Debian 12+ | [Testleaf-linux.deb](../../releases/latest/download/Testleaf-linux.deb) | `sudo apt install ~/Downloads/Testleaf-linux.deb` |
| Other Linux (64-bit) | [Testleaf-linux.tar.gz](../../releases/latest/download/Testleaf-linux.tar.gz) | `tar xzf Testleaf-linux.tar.gz -C ~` and run `~/Testleaf/Testleaf` |

This repository holds only the app files, not source code.
